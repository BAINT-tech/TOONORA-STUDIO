Toonora Studio

Put ALL these files in the same folder, then open index.html in Chrome, Edge or Safari.
No server or internet needed.

index.html           page layout
style.css            styling
app.js               the studio (script import, voices, timeline, export)
character-max.js     Max (art + details)
character-mia.js     Mia
character-oliver.js  Oliver

New character: copy a character-*.js file, change the name, art and details, and add one <script> line in index.html.
